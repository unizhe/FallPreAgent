# P4 开发任务 · 跌倒概率与事件评估

2026-11-18 离线评估工具与冻结批次盘点已在修订五通过，人工标注准备材料已在修订一通过。当前跌倒事件覆盖为 0/2，可计分窗口为 0。按[本次复审结论与开发任务](../output/agent-review/stage-05/reviewer-approval-data-prep-01-revision-01.md)进入人工盲审与回执接收，新增云请求预算为 0。

在 FallPreAgent 仓库实施 P4。前置结论见 output/agent-review/stage-04/reviewer-approval-revision-02.md。交付可复跑的离线评估入口和实测报告，回答两个问题：合格窗口的估计与人工标注有多一致？计入未形成窗口的片段，系统能覆盖多少真实跌倒事件？

1. **冻结数据与标签。** 盘点已有授权素材、标注与推理记录，按视频、人物、机位、来源及原文件摘要登记。定义标签目标为来源窗口内是否观察到跌倒过程，区分正常活动、已倒卧、可见跌倒过程、无法判定，记录事件起止、标注者或既有标注来源及分歧。视频级类别不能直接赋给每个窗口，模型输出不能生成真值。标签不足则提供可填写的标注清单和待判片段。
2. **建立可追溯评估表。** 每行关联视频、窗口、真实样本数、映射/策略/头/模型版本、标签、门控结果、拒绝原因、概率来源及任务标识。保留无窗口、失败和重复观测并分别计数。旧真实 ready 仅关联原输入。v2 重建可以用于测量证据覆盖；只有相同输入、配置与版本的真实预测才可用于相应的概率评估。mock 和合成夹具只用于验证评估工具。
3. **固定分组与对照。** 在拟合和选阈值前冻结训练、校准、测试分组。来自同一原视频的窗口、重采样副本和重复 run 必须同组，记录人物和机位交叉情况，以及 C/D 头既有训练数据的重叠。留出集保持独立。对照既有视觉事件基线、原始模型估计、候选校准加门控策略，记录各自实际可用的数据范围。
4. **分开报告窗口与事件。** 对有可判标签和同版本真实分数的窗口报告样本数、正负例、独立组数、Brier 分数、ECE 和带每箱样本数的可靠性图。记录分箱和不确定性计算方法。对全部视频报告时长、资格覆盖率、弃权率及原因；对标注事件按预先定义的匹配规则报告漏检数、误报数及每小时误报、源时间与端到端墙钟延迟 p50/p95。明确门控漏掉的事件数，并单列请求数、缓存率、可核验用量和费用。分母为零或缺少时间/费用证据的指标标为不可计算。
5. **校准的证据条件。** 仅在有可用正负例、足够独立分组及留出数据时，在校准集拟合，并报告同一测试集上的校准前后表现。给出样本规模与不确定性；材料不足则提交缺口表、需要补标或补采的场景及规模依据。当前两条正常片段旧分数不能独立支持校准或跌倒检出率。部署概率与报警策略维持现有版本，待评估结论另行审核。
6. **执行与交付。** 先用本地数据与已有记录完成可做部分。P3 的 6 次云预算已耗尽。需要新增真实预测时，在报告中列出按组抽样方案、预计调用数/重试上限及费用，供单独确定 P4 预算。保存数据清单、分组、结果表、图、代码版本、复跑命令、测试/退出码，提交 output/agent-review/stage-05/report.md 和独立 runs/decision-stage05-* 目录。用已知小例验证分组无泄漏、弃权计数、事件匹配和指标，再跑便携回归与发布边界检查。区分工具已验证、人工数据足以评估、候选校准达到验收条件三种结论。
