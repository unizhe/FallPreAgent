先执行 `project_resources.py doctor --profile perception-chain`，再做实际模型 smoke。审核已确认资源存在，但未执行推理。复用资源解析器与 C/D 头资源；明确本次选用的既有头变体，记录模型/头 SHA、预处理、策略、问题版本，不更改训练权重。缺模型或运行依赖时报告具体缺项并完成不依赖它的接口工作，不用 fixture 冒充真实推理。

保留同目标真实观测不少于 8 次、1.5–2.5 秒 ST 窗口、ST 距触发观测不超过 0.6 秒等已审核质量门。多人、失去目标、机位移动、断续、旧 epoch/generation、缺头/缺 ST、未来或过期结果均按原合同降级。不能把插值帧算成真实观测，不能用 ST/头分数冒充决策概率。ST 和头共享骨架，不宣称独立传感器确认。

主事件确认、恢复和现有模拟执行权限保持原职责；Agent 决策旁挂。模型概率低或不可用不反写主事件。页面须能同时显示主事件 confirmed 与决策 unavailable。

## 2. 本地 API、身份和去重

按总方案新增以下接口，保留未启用 Agent 的 `/infer` 兼容性。选择 provider/网络权限仅来自服务启动配置，默认 off；浏览器不能通过请求体启用真实网络或指定任意模型/路径。

| 接口 | 最小合同 |
| --- | --- |
| `POST /api/v1/agent/runs` | request_id、source_type → 服务端 run/session/stream、资源与 provider 状态；重复创建幂等，不同内容复用 ID 为 409 |
| `POST /infer` + `X-Agent-Run-Id` | 绑定 run/stream 的 JPEG 和源时间；附加 agent receipt，不等待云结果 |
| `GET /api/v1/agent/runs/{run_id}/latest` | 原有当前投影：窗口、概率类型、时效、pending 策略、状态/原因、历史区分 |
| `GET /api/v1/agent/runs/{run_id}/decisions?after_id=…&limit=…` | 持久单调结果游标分页；乱序完成、同源时间和重启时不漏记录；限制 page size |
| `POST /api/v1/agent/runs/{run_id}/stop` | 幂等停止；拒收新帧、清理/收束在途任务，历史仍可查询 |
| `POST /api/v1/agent/decisions/{decision_id}/feedback` | request_id、expected_version、fall/non_fall/uncertain；反馈追加/CAS，不改模型原结果；备注若支持仅在本地保存 |

所有新 GET/POST 复用本机 Host、Origin、X-Session-Token 防护与会话归属校验，不能仅凭 run_id 跨会话读取。请求体/图像/尺寸/队列/分页有限制，日志不打印 token、图片、密钥和原错误正文。

帧幂等在 `infer_live` 前实现：相同 run、源时间、图像摘要、推理选项返回原 receipt，不能再次推动模型状态或新增任务；同时间不同内容/选项返回 409。并发相同帧也只能推理一次。处理失败/进程中断不得留下永久 in-flight。视频 seek、换文件、生产者重启要新建 run，不复用旧流时间；消费者重启仍按 P1/P2 语义恢复。

来源排序决定当前结果，结果游标决定增量历史，两者不要混用。数据库恢复和多连接必须保留 service_instance_id 约定、provider/model 隔离、当前与历史边界。

## 3. 异步执行、补采和停止

复用 DecisionLoop/DecisionWorker/DecisionStore，使用线程拥有的 SQLite 连接。`/infer` 只等待本地感知、登记与 receipt，不等待云调用，不在持有引擎锁/数据库写事务期间等待网络。用阻塞 transport 对照证明 `/infer` 和 latest 查询不受云请求的 3 秒预算拖住；记录本地视觉耗时，不能承诺视觉模型零延迟。

保留每任务总网络预算 3 秒、至多一次重试、子进程隔离与有界回收、每流在途限制/普通窗口合并/关键转移保留/背压。同一帧重放、普通重复窗口、页面重复轮询不多发请求。补采等待真实新观测，最多一次子决策；视频暂停、EOF、换人、停止、超时后 workflow 必须终态。EOF 后可查历史，但停止流不把历史概率标为当前。

清楚定义接口登记和任务持久化边界；崩溃后补齐已接受但未登记的快照，不能丢决策或静默重做视觉状态。服务重启须验证 run 是否可恢复；不能给旧结果刷新时间戳。远端不提供 exactly-once 保证的限制保留在报告中。

## 4. Safari 展示

在已有页面增加 Agent 区域：运行/停止、资源阶段状态、当前决策概率、来源窗口、未校准提示、provider/model、状态及原因、历史与人工反馈。不可用/不足/过期时显示空值和具体原因，不显示为 0%，不拿旧概率填充当前卡片。pending 沿用旧 ready 时显示原窗口及正在等待新结果的提示；mock 明确标识合成概率。

约 500 ms 轮询即可；慢响应不得使旧 run 的返回覆盖新 run，结束时清理轮询和请求。视频 seek/结束、暂停恢复、断网、重复开始/停止要有明确行为。无 Key 内容进 HTML、JS、API 或浏览器存储。

浏览器验证默认仅 Safari，复用任务标签页；不启动 Chrome/Chromium。如果工具不能控制 Safari，提供可复现的本机启动步骤和待验证清单，诚实标注未完成 UI 实测，不用 WebKit 结果冒充 Safari。

## 5. 分层验证与调用预算

先完成全部无网络回归：接口权限/跨 run 隔离、帧并发幂等/冲突、游标分页/乱序、慢云与本地接口分离、配置切换、期限/重启/停止/EOF/补采、反馈 CAS、缺资源与质量门，以及 P0–P2 全部回归。fixture 用于接口故障测试时清楚标注。

随后使用项目已有且授权用于实验的正常活动与跌倒录像，按真实源时间播放，经同一 `/infer` 路径跑真实 YOLO/ST/头。优先复用既有授权实验素材，记录其来源/本地摘要/选段；若找不到授权素材，明确报缺，不制造合成视频冒充真实。先 provider off 检查真实证据和质量门，再进行有限真实调用。

本阶段授权通过显式 `--provider aliyun --enable-network`（或等价、报告中写明的服务参数）使用已有 `.env`，仅发送白名单证据摘要；不上传图像、视频、完整骨架或自由文本。P3 整轮实验最多 6 次 HTTP 发送，包含重试/子任务/重启，计数持久化；预算耗尽转明确终态，不能每次重开页面获得新预算。规划正常与跌倒各一个合格窗口、重复输入验证，其余故障用离线替身。没有合格证据就不发送，不能放宽门槛。

至少取得一次由真实视频完整链路产生并持久保存的合法 Aliyun ready 结果，展示其未校准概率、来源窗口与请求追踪；同时证明不足/失败时当前值为空以及同输入不新增调用。不要求跌倒分数高于正常，更不要求固定准确率。若合格窗口始终不足、预算内所有响应均失败或 Safari 实测未完成，提交“已实现但验收有缺口”，不可宣称 P3 完成；不得反复改问题/换模型/放宽分布合同追求通过。

已知限制：P2 跌倒合成输入的一个新响应因 next_step 分布和不合法被拒绝，原响应值未保存。P3 保持严格拒绝和诊断，不能自动归一化隐藏问题；只需对新证据如实记录。
